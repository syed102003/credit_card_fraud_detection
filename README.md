# ❤️ Heart Failure Mortality Prediction

This project builds a **Machine Learning model** to predict **mortality risk in heart failure patients** using clinical health indicators.  
The goal is to support early diagnosis, risk assessment, and medical decision-making using data-driven insights.

---

## 📌 Project Overview

Heart failure is one of the leading causes of death worldwide.  
Using machine learning, we analyze patient medical data to identify patterns and predict whether a patient is at risk of mortality.

This project includes:

- Data loading & cleaning  
- Exploratory Data Analysis (EDA)  
- Feature scaling  
- Model training (Logistic Regression, Random Forest, etc.)  
- Model performance evaluation  
- Visualizations (confusion matrix, ROC curve)

## 📈 Key Insights
- Dataset is **extremely imbalanced** (fraud cases are <1%).  
- Fraudulent transactions tend to have **lower amounts**.  
- PCA features **V10, V14, V17** strongly correlate with fraud.  
- Fraud does not occur uniformly over time; some time windows have higher fraud activity.  
- Density plots show clear separations between fraud vs non-fraud for several PCA components.
